# نظام إدارة وفواتير ومستودع ملفات الرخام والجرانيت
### خالي أحمد جلال - الإصدار الرسمي 2026

منظومة سحابية وإلكترونية متكاملة لإدارة مصانع وورش وتجارة وتصدير الرخام والجرانيت، وإصدار الفواتير بالاسطنبة المعتمدة، مع مستودع مركزي لكافة ملفات وفواتير الشغل.

---

## 🌟 أبرز مميزات النظام

1. **اسطنبة الفاتورة الرسمية (مطابقة 100%):**
   - ترويسة الفاتورة الصفراء: التاريخ، العميل، السائق، رقم السيارة / الكونتر، مكان التحميل، المشرف، رقم الفاتورة.
   - جدول البنود: رقم الطرد، رقم البلوك، نوع الخامة، عدد، طول، عرض، المسطح (م٢)، السعر، الإجمالي، وخيار **"فري"** للقطع المجانية والعينات.
   - **ملخص الجرار التلقائي:** تجميع آلي فوري لحمولة السيارة حسب كل خامة ومقاس.
   - **تعديل الفاتورة في أي وقت:** إمكانية تعديل أي فاتورة وإعادة ربطها بأي عميل وتحديث الحساب المالي فورياً.
   - تصدير إكسيل حقيقي (`.xlsx`) بالصيغ الأصلية (`=PRODUCT(...)` و `=SUM(...)`).
   - إرسال ومشاركة مباشرة للعميل عبر **واتساب (WhatsApp)** بضغطة زر.
   - إرفاق صور البضاعة والحمولة والشيكات والإيصالات لكل فاتورة.

2. **مستودع ملفات الشغل المركزي (File Repository):**
   - أرشفة وتصفح منظم لجميع ملفات وفواتير العملاء التاريخية والحالية.
   - تحميل الملفات الأصلية مباشرة.
   - معاينة سريعة لملفات الإكسيل والـ PDF والصور من داخل المتصفح.

3. **الحسابات والديون والشركاء:**
   - كشوف حسابات تفصيلية للعملاء ومتابعة المتبقي والمدفوع ودعم التحويلات والدينار الليبي.
   - حساب الشركاء (أحمد وحسين): متابعة مصاريف الشغل (أوناش، نقل، إكراميات، بياتة) ومقبوضات الشغل.
   - حسابات مصانع وورش النشر والتلميع ومسحات الرخام.
   - مركز تفاعلي لتعديل وتحديث أسعار الخامات وتطبيقها تلقائياً.

## 🚀 التشغيل المحلي (Local Run)

```bash
# 1. تثبيت المتطلبات
pip install -r requirements.txt

# 2. تهيئة قاعدة البيانات بالبيانات الأولية
python seed_data.py

# 3. تشغيل الخادم
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```
افتح المتصفح على: `http://localhost:8000`

## 🌐 النشر على الإنترنت والحصول على دومين مجاني (Live Domain)

### الخيار 1: النشر على Render.com (مجاني بدومين HTTPS)
1. قم بربط هذا المستودع في حسابك على [Render.com](https://render.com).
2. اختر **New Web Service** وحدد هذا المستودع `marble-granite-erp`.
3. اضغط **Deploy**.
4. ستحصل فوراً على رابط ودومين مباشر مثل:
   `https://marble-granite-erp.onrender.com`
   تستطيع فتحه من هاتفك أو أي جهاز في أي مكان!

### الخيار 2: النشر على Railway أو Koyeb أو Fly.io
الملفات جاهزة بـ `Procfile` و `render.yaml` و `requirements.txt` وتعمل تلقائياً.
